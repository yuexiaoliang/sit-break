# 日程按实际轮次推进

日程按轮次顺序执行，保留现有休息交互：工作倒计时结束后先提醒，由用户选择“再等等”或开始休息；开始后按本轮休息时长倒计时，休息结束后进入下一轮。时间表中的时刻是预计时间，会随用户操作变化，因此不增加按预定钟点强制结束休息的模式。

这一选择优先保留用户对工作中断时机的控制，适应无法立即起身休息的实际情况；代价是后续轮次不能保证在预览中的原定钟点开始。

## 执行时段边界

执行时段结束时，停止尚在进行的工作计时，收起待处理的休息提醒；已经开始的休息可以完成。休息结束时若仍处于停用时段，则保持停用；若新的执行时段已经开始，则从新时段第一轮开始，不同时运行两份计时。上一时段未完成的安排不再补做。这使午休等停用时段保持安静，同时保留已经开始的休息的完整性。

## 自动检测离开

开启现有“离开自动重置”功能时，以本轮休息时长作为离开是否足够久的判断阈值。尚在工作倒计时中离开够久，只重置当前轮的工作计时，不跳轮；已经进入休息提醒后离开够久，则视为本轮已经休息，进入下一轮。此判断只确认离开了电脑，不据此认定用户完成了休息内容描述的活动。

## 手动控制

手动暂停保持到用户手动恢复，期间冻结倒计时和空闲处理，执行时段边界仍生效。暂停中的已开始休息不因时段结束被取消，恢复后可以继续完成；过期的工作计时和待处理提醒不恢复。

重置重新计当前轮的工作，不消耗该轮；提前结束休息则结束本轮。两者都遵守当前有效时段，不在停用时段启动工作。这些操作沿用现有入口，不增加新的设置项。
