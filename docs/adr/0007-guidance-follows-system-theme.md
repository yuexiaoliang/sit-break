# 休息浮窗与 HTML 模板统一跟随系统主题

休息浮窗改为跟随系统亮暗主题，替代原来休息中始终使用深色的规则。HTML 指引模板也跟随系统主题，使按模板制作的本地用户指引能与浮窗外框保持一致；这项规则同时适用于纯文字休息浮窗。

向 HTML 作者提供按用途命名的标准颜色变量、亮暗两套配色和可复制的生成提示词，可保存的示范 HTML 使用同一套约定。首版的颜色配置以变量和模板提供，不增加在应用设置中为每份指引调色的入口。

主题适配保证覆盖保存后导入的示范和按模板制作的 HTML。用户添加的其他网页按其自身支持的样式展示，不强制修改其配色。

这一选择使生成提示词与作者模板成为配色约定的共同入口，便于用户制作适合小浮窗的内容；代价是需要同时维护亮暗两套配色，并在后续调整变量约定时考虑已生成 HTML 的兼容性。
