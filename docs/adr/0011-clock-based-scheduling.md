# 日程按本地钟点切换轮次

状态：已采纳。替代 [ADR 0001](0001-round-based-scheduling.md) 与 [ADR 0003](0003-restore-round-progress.md) 的日程计时规则，并修订 [ADR 0004](0004-preserve-active-round-on-edit.md) 的时长生效规则。

实际使用中，09:00–12:00 每轮工作 55 分钟、休息 5 分钟的日程，10 点多才开始运行时，11 点多仍显示第 1 轮。用户确认希望始终按钟点走，11:00 自动进入第 3 轮。现在用同一组计划时刻生成预览并确定当前轮次：从执行时段起点排出完整轮次，按本地钟点进入对应的工作或休息窗口，放不下完整轮次的余量保持待机。

> [ADR 0012](0012-full-scheduled-break-duration.md) 更新了已开始休息的计时与恢复规则。以下保留原决策。

仍由用户决定是否开始本次休息。晚开始只使用窗口内剩余时间；再等等最多 5 分钟，到期时若窗口已结束则不再提醒；提前结束收起浮窗。到下一轮或执行时段结束时，旧提醒和旧休息均收起。暂停只静音和收起提醒，离开自动重置仅适用于简单计时。

首次打开、退出重开、唤醒和切换到日程计时都用当时的本地钟点定位，不补发已过期的提醒。重开保留手动暂停；同一计划轮次仍有效时，保留本轮内容以及休息窗口内已开始、推迟或结束的选择，但按当时钟点计算剩余时间。升级时忽略旧版保存的轮次和剩余时间。

保存时长、边界和启用规则后立即对齐新计划；当前轮次身份未改变时保留已选定的休息内容和动作指引。预览的「草稿计划」展示未保存的安排，「当前进度」展示已生效的当前轮和已保存的后续计划。简单计时仍按实际倒计时运行。
