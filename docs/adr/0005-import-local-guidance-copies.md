# 本地动作指引由应用保存导入副本

导入本地视频或 HTML 时，由应用保存一份副本，之后使用该副本展示指引。移动、改名或删除原文件不影响已配置的指引；编辑原文件不会自动改变指引，更新时需要重新选择并导入文件。

相比持续引用原文件路径，这一选择优先保证已配置指引的可用性，代价是额外的本地存储空间，以及更新时需要重新导入。应用保存副本也使当前轮次能够在用户修改配置后继续使用原来选定的指引，遵循[编辑日程保留正在执行的轮次](0004-preserve-active-round-on-edit.md)。

首版 HTML 以单个文件为交付单位，支持文件内的样式与脚本，图片等素材嵌入文件。来源与离线边界按 [ADR 0008](0008-local-files-only-guidance.md) 收紧为本地文件导入，不再加载在线资源。
