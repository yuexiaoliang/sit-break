# 多份日程保持单一执行

允许保存多份日程，每份日程具有独立的启用开关，并按指定日期执行一次或按选定星期每周重复。同时启用的日程之间，以及同一日程内部，有效执行时段不能重叠。修改或启用造成冲突时，指出冲突位置并保留原有效配置，由用户调整后再生效，不通过优先级自动选取其中一份。

这一约束保留工作日、周末等不同安排的灵活性，同时让用户始终能确定正在执行哪一份日程，避免引入优先级、覆盖关系和多份计时并行的额外心智负担。

## 本地日期与日内时段

日程使用电脑本地时间，每个执行时段具有明确的开始与结束时间。本次范围按自然日编排，跨午夜的安排拆成两段，分别设置其执行日期或星期，使重复规则与日期的对应关系保持直观。

## 与简单计时共存

通过一个默认关闭的“使用日程”总开关选择计时方式。关闭时完整保留原有简单计时，设置页直接显示工作时长与休息时长，不要求用户先建立日程。开启后才展开详细安排，只按启用的日程执行，没有有效安排的时间保持待机，不自动退回简单计时。各份日程仍保留独立的启用开关。

简单计时的全局时长与详细日程分别保留，切换不会清空另一种方式的配置。提示音、开机自启、离开自动重置、语言与提醒小字由两种方式共用；Windows 继续提供悬浮计时条开关及大小设置，macOS 继续使用菜单栏。已有的开始休息、再等等、暂停、重置和提前结束入口继续保留。

这一补充来自用户对原型 A 的反馈：现有版本应继续服务只需要简单提醒的用户，详细安排是按需开启的能力，不能成为所有用户必学的设置流程。A 作为继续调整的基础，不代表所有界面细节已最终确认。
