# 动作指引仅支持导入本地视频

用户于 2026-10-15 进一步取消 HTML，动作指引只通过系统文件选择器导入本地视频。来源选项仅保留“不使用指引”和“本地视频”，同步移除 HTML 导入、页面展示、模板、示范、制作提示词及隔离页面设施。

此决定取代 [ADR 0008](0008-local-files-only-guidance.md) 中的 HTML 范围，减少页面脚本、交互与原生平台验收的复杂度，代价是用户需要将活动说明准备为兼容的 MP4 视频。应用继续保存视频副本；提醒与单轮归属、当前轮保留、退出恢复以及系统主题规则不变。

开发测试版遗留的 HTML、在线及内置指引在读取设置时清理，保留已有文字、日程、有效本地视频和其他偏好。只有被取消指引且没有文字的空提醒条目移除；旧 HTML 副本按未引用资源回收。
