# 日程休息从确认时开始计满

状态：已采纳。更新 [ADR 0011](0011-clock-based-scheduling.md) 中已开始休息的计时、换轮和恢复规则。

计划钟点用于排定工作和休息提醒窗口。用户在窗口内选择「开始休息」后，从本轮设定的完整休息时长倒计时，跨轮、时段或午夜时仍保留这次休息及其内容。休息结束后按当时的本地钟点接回日程，避免一次晚开始使当天余下的轮次不断延后。

提醒窗口关闭后，尚未开始的休息到期。已经开始的休息按经过的时间倒计时，重开或唤醒时恢复剩余时间。主动关闭该日程、删除所在时段或切换计时方式会立即结束这次休息。保存其他时长或边界时保留正在进行的休息。
