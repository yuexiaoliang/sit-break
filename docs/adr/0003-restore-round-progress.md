# 关闭应用与电脑休眠分别处理

## 关闭应用

同一份日程在同一天、同一执行时段内退出后重新打开，恢复原有运行进度，应用关闭期间视为暂停，不将这段时间计入工作或休息。这样既保留用户已执行到的轮次，也不会根据预排钟点推测应用关闭期间完成了哪些安排。

首次打开或已经进入新的执行时段时，从当前时段第一轮开始；处于停用时段时保持安静。过期时段的进度不用于补做或补发提醒。

## 电脑休眠

应用仍在运行时，电脑休眠视为离开电脑，睡眠时间不计入工作时间；开启“离开自动重置”时，按相应的离开规则处理。已经开始的休息按实际经过时间计算：唤醒时若已休满，则结束本轮，并根据当时的执行时段继续；若仍有剩余时间，则继续本次休息。

关闭应用表示主动停止计时，因此恢复时保留剩余时间；电脑休眠期间应用仍在运行，已经开始的休息可以继续。这一区分避免将睡眠误算为工作，同时保留休息经过的真实时间。

## 主动启停与切换计时方式

主动关闭后再启用日程，或切换计时方式，视为重新开始，不恢复此前的日程进度。已经开始的休息允许完成，随后采用当前选择的计时方式；日程计时从当时有效时段的第一轮开始，没有有效时段则待机。这让主动改变安排与暂时退出应用具有不同且明确的含义。
