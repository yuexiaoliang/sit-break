# 动作指引由提醒条目或单轮休息独立配置

每个提醒条目或每次休息独立配置最多一份动作指引，文字与指引分别可选；文字即使描述多项活动，也不拆成多个动作及其指引。没有填写文字时仅展示指引，不补充通用提示文字。

日程某轮配置了休息内容或动作指引时，使用该轮的文字与指引作为一组展示内容：只有文字就展示纯文字，只有指引就仅展示指引。两者都未配置时，才随机选用一个提醒条目，并一起使用该条目的文字与指引，避免将不同来源的文字和指引混配。

用户需要灵活使用自己制作或他人分享的视频与 HTML 文件，因此指引归属于具体提醒或休息安排，不建立按动作统一管理和引用的动作库。同一个动作在不同提醒或休息中可以使用不同指引；来源按 [ADR 0008](0008-local-files-only-guidance.md) 收紧为本地文件导入。

这一选择保留自由文本和内容来源的灵活性，代价是多处使用相同动作时，需要分别维护各处的指引配置。
