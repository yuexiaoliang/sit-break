# 动作指引只接受本地文件导入

本记录中的 HTML 范围已由 [ADR 0009](0009-local-video-only-guidance.md) 取代，当前只保留本地视频；以下保留当时的来源调整背景。

用户将首版范围收紧为从电脑选择本地视频或单文件 HTML，取代原规格中的在线网址和直接选择内置指引。不提供粘贴、输入 HTML 源码的配置入口；示范和模板作为可保存的制作材料，保存为文件后再走普通导入流程。

导入 HTML 按单文件离线内容运行，素材嵌入文件，保留页内脚本、按钮、动画与锚点；关闭联网资源和外部页面导航。此决定减少来源、网络失败与导航的交互和验收负担，代价是用户需要先准备完整文件；导入副本、当前轮保留和恢复规则继续遵循既有决策。
