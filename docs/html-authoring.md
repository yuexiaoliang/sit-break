# 为 Sit Break 制作单文件 HTML 指引

动作指引只接受本地文件选择与导入。应用不提供 HTML 源码粘贴或编辑入口，也不接受在线网址。在“制作 HTML 指引”中可以保存示范和模板、复制只读的生成提示词；先将制作结果保存为文件，再导入。

## 从模板开始

1. 保存 HTML 模板，用文本编辑器修改标题、说明与要点；或复制生成提示词，把其中 `【替换为你的内容要求】` 改为自己的要求，再交给你选择的 AI。
2. 将结果保存为 UTF-8 编码的单个 `.html` 文件。页面的样式与脚本直接放在文件里的 `<style>`、`<script>` 中。
3. 在提醒条目或单轮休息中选择“本地 HTML”，导入该文件，保存设置后开始一次休息。只配置指引时可以不填写提醒文字。

应用会保存导入副本。原文件之后的修改不会自动更新已配置指引，需要重新导入。保存出的示范文件也可以按相同路径重新导入。

## 为实际内容区域排版

HTML 只占浮窗中的指引区域。典型内容宽约 374 逻辑像素；高度会随屏幕可用区域、提醒文字和状态提示变化。420×460 是媒体浮窗的目标尺寸，不是网页可用尺寸。

从可变窄的布局开始：设置 `meta viewport`、`box-sizing: border-box`，不要给页面设置固定宽度或大于视口的 `min-width`；长文字可断行，图片和 SVG 的宽度不超过 `100%`。以短标题和少量要点优先呈现内容，其余内容用折叠区或网页内部纵向滚动承载。不要固定页面高度、禁用滚动或将关键操作固定到整个屏幕的角落。

网页仅负责内容和轻量页内交互。休息倒计时、暂停和结束按钮由浮窗提供，不需要在 HTML 中再做一套；网页的交互也不会改变休息时长。

## 单文件资源与脚本约定

图片使用内联 SVG 或 `data:` 图片，所有素材嵌入同一文件。HTML 完全离线运行，外部图片、字体、脚本、样式或媒体不会联网加载。应用不打包旁边的图片文件夹，不支持依赖 `./image.png`、本机绝对路径、文件夹或压缩包的网站项目。

普通的按钮、折叠区、CSS 动画和内联脚本可用。脚本只操作当前页面，不访问父页面、应用设置、Tauri 命令或任意本地文件；不要依赖跨页面存储、下载、弹窗、新 iframe、表单提交、第三方脚本、网络请求 API 或跨源权限。页面内锚点可以用于自己的内容。外部链接、弹窗、脚本跳转和自动跳转均被阻止，内容始终留在导入文件中。

## 系统亮暗主题

隔离的 HTML 不继承浮窗的 CSS，必须自带下表配色。模板在 `:root` 中声明浅色变量，在 `@media (prefers-color-scheme: dark)` 中覆盖深色值，并声明 `color-scheme: light dark`。所有背景、正文、边框和按钮都从用途变量取值。

| 变量 | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `--sb-background` | 页面背景 | `#ffffff` | `#181d1b` |
| `--sb-surface` | 内容块背景 | `#f0f8f4` | `#202b25` |
| `--sb-text` | 正文、标题 | `#1f2a24` | `#eef4f0` |
| `--sb-text-secondary` | 说明文字 | `#52665a` | `#aebcb3` |
| `--sb-border` | 边框、分隔 | `#d7e6dd` | `#35483d` |
| `--sb-accent` | 强调文字、主要按钮 | `#1d7a56` | `#4fe0a8` |
| `--sb-accent-strong` | 较强强调色 | `#176044` | `#2fc186` |
| `--sb-on-accent` | 主要按钮文字 | `#ffffff` | `#10261c` |
| `--sb-accent-soft` | 浅强调背景 | `rgba(47, 193, 134, .1)` | `rgba(79, 224, 168, .12)` |
| `--sb-accent-border` | 强调边框 | `rgba(29, 122, 86, .22)` | `rgba(79, 224, 168, .2)` |
| `--sb-control-background` | 次要按钮背景 | `rgba(31, 174, 116, .08)` | `rgba(255, 255, 255, .07)` |
| `--sb-control-hover` | 次要按钮悬停背景 | `rgba(31, 174, 116, .15)` | `rgba(255, 255, 255, .12)` |

主题只通过 CSS 更新，不重载页面，也不在 `matchMedia` 回调中重置变量、折叠状态或滚动位置。深色主要按钮的文字使用 `--sb-on-accent`，不要固定白色。

应用不强制改色其他网页。使用自己的固定配色是允许的，但只有保存后导入的示范和遵循模板的页面保证跟随系统亮暗。

## 交付前检查

在实际浮窗里检查有文字和只有指引两种情况，确认窄视口无横向溢出、长内容可纵向滚动、倒计时与应用按钮一直可见。展开说明或点击按钮后切换系统亮暗，确认交互和休息时间继续；断网时检查内嵌素材。示范和模板均不需要外部资源。
