# 动作指引的系统主题配色

休息前的提醒页、休息中的浮窗和按模板制作的 HTML 都以系统亮暗为主题来源，不提供额外的主题开关。浮窗的共用颜色定义位于 `src/guidance-theme.css`，使用 `prefers-color-scheme: dark` 覆盖浅色默认值。

## 作者使用的语义变量

以下变量以用途命名，HTML 模板和可保存的示范沿用相同名称与取值。页面的内容背景使用不透明的 `--sb-background`；`--sb-surface` 用于卡片或提示块。

| 变量 | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `--sb-background` | 页面背景 | `#ffffff` | `#181d1b` |
| `--sb-surface` | 内容块背景 | `#f0f8f4` | `#202b25` |
| `--sb-text` | 正文、标题、倒计时 | `#1f2a24` | `#eef4f0` |
| `--sb-text-secondary` | 说明文字、次要操作 | `#52665a` | `#aebcb3` |
| `--sb-border` | 内容分隔和边框 | `#d7e6dd` | `#35483d` |
| `--sb-accent` | 强调文字、主要按钮渐变起点 | `#1d7a56` | `#4fe0a8` |
| `--sb-accent-strong` | 主要按钮渐变终点 | `#176044` | `#2fc186` |
| `--sb-on-accent` | 主要按钮上的文字 | `#ffffff` | `#10261c` |
| `--sb-accent-soft` | 徽标、浅强调块背景 | `rgba(47, 193, 134, .1)` | `rgba(79, 224, 168, .12)` |
| `--sb-accent-border` | 强调块边框 | `rgba(29, 122, 86, .22)` | `rgba(79, 224, 168, .2)` |
| `--sb-control-background` | 次要按钮背景 | `rgba(31, 174, 116, .08)` | `rgba(255, 255, 255, .07)` |
| `--sb-control-hover` | 次要按钮悬停背景 | `rgba(31, 174, 116, .15)` | `rgba(255, 255, 255, .12)` |

浅色强调文字采用原有品牌绿色的较深版本，深色采用较亮版本，以保持正文和按钮可读。不要把主要按钮上的文字固定成白色：深色按钮需要使用 `--sb-on-accent`。

浮窗还有 `--sb-window-background`、`--sb-window-border`、`--sb-window-shadow` 和 `--sb-ring-background`。这些变量保留原有半透明外框、阴影和圆环效果；HTML 内容不需要复制窗口外框，也不应自行实现应用倒计时。

## 在原界面内更新主题

浮窗通过 CSS 媒体查询更新颜色，不监听主题来重建 DOM，不重新获取计时状态，也不重新打开窗口。运行中切换主题只改变呈现，已有倒计时、暂停状态、文本选择和滚动位置由原实例保留。纯文字的窗口尺寸、圆环和按钮布局不因主题变化而改变。

随应用提供的 HTML 模板在自己的 `:root` 中声明同一套变量，并以 `@media (prefers-color-scheme: dark)` 覆盖深色值；模板根元素声明 `color-scheme: light dark`，让浏览器原生控件随主题适配。不要根据主题更新执行页面重新加载，或重置作者脚本中的交互状态。隔离页面不能依赖父页面 CSS 的自动继承，单文件 HTML 必须自带配色定义。

其他网页保留自身样式，应用不向其注入强制改色规则。提醒条目和单轮休息的“动作指引”下提供“制作 HTML 指引…”入口，可离线保存示范和模板、复制完整生成提示词，并查看实际内容区域与配色说明。完整作者约定见 [HTML 制作说明](html-authoring.md)。产品内配色表直接读取随包模板的声明。

## 原生验收

构建只能证明样式可随应用打包。macOS、Windows 的真实浮窗仍需分别核对：提醒页和休息页的浅深色外观、运行中切换系统主题、暂停后的切换、长文字滚动，以及窗口尺寸和计时状态保持。原生验收记录由整项功能的集成验证统一保存。
