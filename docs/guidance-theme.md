# 应用与动作指引的主题配色

v0.5.0 起，设置、托盘面板、休息浮窗和 Windows 悬浮计时条共用浅色、深色、跟随系统三种外观。通过设置侧栏底部或“通用设置”选择；设置窗口即时预览草稿，保存后各窗口同步。

默认跟随系统。旧配置缺少外观字段或包含未知值时也回退为跟随系统，不重置已有日程和其他偏好。这扩展了原先浮窗仅跟随系统的规则，见 [ADR 0010](adr/0010-react-mantine-ui.md)。

## 配色与共用控件

颜色按用途定义在 `src/app.css`；`src/theme.tsx` 为 Mantine 提供雾紫色板、系统字体与组件默认样式。

| 变量 | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `--surface` | 主要内容背景 | `#fbfaf9` | `#222126` |
| `--surface-subtle` | 侧栏、输入与日程卡片 | `#f3f1f3` | `#29272e` |
| `--surface-hover` | 悬停或选中表面 | `#eeebf0` | `#343039` |
| `--surface-border` | 边框与分隔线 | `#e4e0e7` | `#403b46` |
| `--ink` | 正文、标题与倒计时 | `#302d36` | `#eeeaf1` |
| `--muted` | 说明与次要文字 | `#706a78` | `#afa8b7` |
| `--accent` | 强调色 | `#74618f` | `#c5b0e2` |

按钮、选择器、开关、时间与数字输入、弹窗和视频控制条共用 Mantine。深色主按钮使用浅紫背景与深色文字，保持阅读对比度。设置窗口采用 18px 圆角，侧栏、正文和弹层遮罩共同裁切；浮窗不使用会超出窗口边缘的大范围 CSS 投影。

## 主题与播放状态

主题变化只更新外观，不重新打开窗口，不重建视频节点，也不改变播放位置、暂停状态、静音状态、文字滚动位置或休息倒计时。播放器只在资源变化、显式重试或休息结束等生命周期事件中更新或释放。

纯文字休息按内容高度在 244–368 逻辑像素之间适配；有视频时使用横向布局，文字在独立区域滚动，计时和结束按钮持续可见。

非必要动效控制在 100–220 毫秒，计时方式内容进入为 160 毫秒。系统启用减少动态效果时，组件与应用样式均减少过渡和动画。
