# 领域文档

本项目采用单一领域上下文：术语表位于仓库根目录的 `GLOSSARY.md`，架构决策记录位于 `docs/adr/`。

## 探索代码前

阅读 `GLOSSARY.md`，以及与当前工作相关的架构决策记录（ADR）。

这些文档尚不存在时，直接继续工作。`/domain-modeling` 会在术语或决策明确后创建相应文档；`/grill-with-docs` 和 `/improve-codebase-architecture` 会调用它。

## 统一术语

功能规格、任务、设计讨论、代码和测试中的领域概念使用术语表约定的名称。需要的概念尚未收录时，先检查项目现有用语，再将确实缺失的术语交给 `/domain-modeling` 处理。

## 架构决策

遵循相关 ADR。提议的改动与已有 ADR 冲突时，明确指出对应记录，并在替换决策前说明为什么需要重新考虑。
