# 分类标签

工程技能提到任务分类角色时，使用下表中的标签映射。

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估。 |
| `needs-info` | `needs-info` | 等待报告者补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可由代理实现。 |
| `ready-for-human` | `ready-for-human` | 需要人工实现。 |
| `wontfix` | `wontfix` | 不予处理。 |

`bug`、`enhancement` 等标签描述任务主题，可以与这些流程标签同时使用。如果项目调整分类用语，修改本表的“GitHub 标签”列。
