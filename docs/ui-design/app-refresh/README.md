# 应用界面改造

采用用户最后一组三张设计图中展示顺序第 1 张作为参考，原图保存在 `reference.png`。布局沿用侧栏结构，配色使用雾紫、浅白与柔黑；三个偏好开关右侧对齐，移除进入箭头，以独立的“编辑日程”文字按钮进入侧栏同一日程页面。

应用实际设置窗口为 720 × 820（根据屏幕工作区收缩） 逻辑像素，主内容可滚动，底部保存操作固定；窄于 610 像素时侧栏收为图标导航，窄于 420 像素时工作／休息时长纵向排列。原图为两种主题的概念画板，实际界面按桌面窗口约束收紧纵向间距，不采用概念图的整张画布比例。

通用按钮、数字输入、时间输入、选择器、开关、单选分段、星期选择、日期选择、折叠面板、弹窗、滑块、提示与滚动区使用 Mantine。Phosphor 提供图标。日程编辑、短文字高度适配、原生窗口拖动与定位、本地视频导入和播放生命周期保留为业务封装；视频控制条也共用 Mantine 控件。

动效控制在 100–220 毫秒：按钮反馈、侧栏内容进入、选择器、预览弹窗与单轮调整折叠。计时数字不做跳动动画，切换主题只更新样式；系统启用减少动态效果时，组件与应用样式均禁用非必要动画。

验证记录见根目录 `design-qa.md`。浏览器外观检查使用隔离数据，不能替代实际 WKWebView／WebView2 的本地文件选择、受控媒体协议和原生窗口定位验收。
