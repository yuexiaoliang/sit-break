# Sit Break v0.8.0

[English](v0.8.0.en.md) | **简体中文**

macOS 菜单栏现在显示一个图标和简短状态。工作时，简单计时显示「工作」，日程计时显示当前轮次。圆角背景的填充随剩余时间从右向左缩短。点击菜单栏项可查看精确倒计时。

- 简单计时暂停后，图标切换为暂停符号，灰色进度停住。
- 日程计时暂停提醒后，图标切换为静音铃，进度继续走。休息完成后若仍在本轮休息提醒窗口内，显示「已休息」。
- 背景按系统菜单栏项的尺寸绘制，按下和松开共用同一个圆角轮廓。

## 升级与兼容

退出正在运行的正式版和测试版后覆盖安装。应用会沿用原正式版的设置、日程和手动暂停选择。测试版使用独立的设置目录。

macOS 需要 12 或更新版本及支持 WebKit 15.4+ 的系统 WebView。Windows 需要 10 或 11 x64 及基于 Chromium 108 或更新版本的 WebView2。macOS 使用本地 ad-hoc 签名，Windows 安装包未签名。安装与使用见[完整使用说明](../../README.zh-CN.md)和[日程使用说明](../schedules.md)。
