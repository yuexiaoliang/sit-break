# Sit Break v0.5.1

**English** | [简体中文](v0.5.1.md)

This update fixes schedule previews and shows whether a round adjustment fits its time period as you edit.

## Schedule Fixes

- Preview schedule opens Draft plan by default and shows complete rounds from the start of each period. Switch to Current progress for estimates based on the running timer.
- If the round cannot fit when you select Add round adjustment, the editor blocks the addition and explains why beside the button. If a shorter round can fit, the editor shows the minutes available for work and break.
- A planned round can finish exactly at the period boundary, including `24:00`. When current progress puts work up to the period boundary, the preview shows the work window for that round.

The macOS preview build was tested with `09:00–12:00` and `13:30–18:30` periods. With 55 minutes of work and 5 minutes of break per round, the draft shows 3 and 5 rounds respectively. The test also covered the feedback when adding a round.

## Upgrading and Compatibility

Quit the old version before replacing it. The app uses your existing regular-release settings and schedules. Preview builds store settings separately. The app requires macOS 12 or later with a system WebView that supports WebKit 15.4+, or Windows 10/11 x64 with WebView2 based on Chromium 108 or later.

The macOS app uses local ad-hoc signing. Windows installers are unsigned. See the [user guide](../../README.md) and the [schedule guide](../schedules.en.md) for installation and schedule setup.
