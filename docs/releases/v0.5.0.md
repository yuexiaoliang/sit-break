# Sit Break v0.5.0

[English](v0.5.0.en.md) | **简体中文**

这次更新重做了应用界面，加入明暗主题与本地视频动作指引，并让两种计时方式更清楚。

## 新功能与改进

- 统一设置、托盘面板、休息浮窗和 Windows 悬浮计时条的控件、间距与雾紫配色。
- 支持浅色、深色、跟随系统，主题保存后同步到各窗口；支持系统减少动态效果设置。
- 用顶部“简单计时／日程计时”选择替代原“使用日程”开关，只显示当前方式的配置。切换保留草稿，保存后生效。
- 日程模式展示已启用日程、重复日期、执行时段和默认时长；无日程或全部停用时提供明确入口。
- 提醒条目和日程单轮调整支持导入本地 MP4／M4V 视频，可以与文字组合，也可以单独展示视频。
- 视频由应用保存副本，原文件移动或删除后仍可使用；默认静音循环，支持播放／暂停、进度与声音控制。
- 纯文字休息浮窗按内容收紧，长文独立滚动；视频休息采用横向布局，保留倒计时与结束按钮。
- 修复 macOS 浮窗变宽后定位越界、单行文字留白过大和外部阴影被裁切的问题；设置窗口增加圆角。
- 保留日程的实际轮次推进、当前轮快照、退出恢复、睡眠与暂停规则，继续支持结束时间 `24:00`。

## 升级与兼容

- 退出旧版后覆盖安装，原正式版的设置与日程继续保留；旧配置的外观默认跟随系统。独立测试包与正式版使用不同配置目录，不自动迁移测试数据。
- macOS 12+，系统 WKWebView 需支持 WebKit 15.4+；Windows 10/11 x64，需 Chromium 108+ 的 WebView2。建议保持系统和 WebView 组件更新。
- 推荐导入 H.264 编码的 MP4；能否播放也取决于系统媒体支持。动作指引仅支持本地视频，开发测试版中的 HTML、在线及内置来源会被清理，文字与有效本地视频保留。
- macOS 应用采用本地 ad-hoc 签名，尚未经过 Apple 公证；Windows 安装包未使用代码签名证书。

## 验证范围

合并前已通过 12 项前端测试、macOS／Windows 常规检查、真实 WebView2 浮窗与本地视频检查，以及 Windows 安装包构建。macOS 原生定位检查覆盖 8 个场景。原生文件选择器与部分 macOS WKWebView 手动交互仍未全面覆盖，不将浏览器预览当作完整实机验收；详见[原生验收范围](https://github.com/yuexiaoliang/sit-break/blob/main/docs/native-webview-check.md)。
