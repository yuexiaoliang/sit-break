# Sit Break v0.5.0

**English** | [简体中文](v0.5.0.md)

This update redesigns the interface, adds light/dark themes and local video guidance, and makes the two timer modes easier to understand.

## Features and Improvements

- Unified controls, spacing, and a soft plum palette across settings, the tray panel, break windows, and the Windows floating timer.
- Light, Dark, and System themes synchronize across windows when saved. Nonessential motion respects system reduced-motion preferences.
- A Simple timer / Scheduled timer selector replaces Use schedules. Only the selected mode's settings appear. Switching preserves drafts; saving applies the choice.
- Scheduled mode summarizes enabled schedules, repeat dates, periods, and default lengths, with useful actions when no schedules exist or all are disabled.
- Reminder entries and individual scheduled rounds can import local MP4/M4V videos, combined with text or shown alone.
- The app stores video copies, so moving or deleting the original does not affect guidance. Videos loop muted by default, with play/pause, seeking, and sound controls.
- Text-only break windows fit their content; long text scrolls independently. Video breaks use a horizontal layout while keeping the countdown and end-break button visible.
- Fixed macOS break windows extending beyond the screen after widening, excessive space around single-line text, and clipped outer shadows. Settings windows now have rounded corners.
- Preserved actual round progression, current-round snapshots, exit recovery, sleep and pause rules, and `24:00` end times.

## Upgrading and Compatibility

- Quit the old app before replacing it. Existing regular-release settings and schedules remain. Older configurations default to the system theme. Separate preview builds have their own data directories; preview data does not migrate automatically.
- macOS 12+ requires a system WKWebView supporting WebKit 15.4+. Windows 10/11 x64 requires WebView2 based on Chromium 108+. Keep system and WebView components updated.
- H.264-encoded MP4 is recommended; playback also depends on system media support. Guidance accepts local videos only. Unsupported HTML, online, and built-in sources from development previews are removed while text and valid local videos are preserved.
- macOS builds are ad-hoc signed and not notarized by Apple. Windows installers are not code-signed.

## Validation Scope

Before merging, 12 frontend tests, macOS/Windows checks, real WebView2 reminder and video checks, and the Windows installer build passed. macOS native positioning checks cover 8 scenarios. Native file pickers and some macOS WKWebView manual interactions are not fully covered; browser previews are not treated as complete native validation. See the [native validation record](https://github.com/yuexiaoliang/sit-break/blob/main/docs/native-webview-check.md), maintained in Simplified Chinese.
