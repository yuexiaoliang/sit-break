# Sit Break LOGO 设计

Sit Break 使用向右上方打开的绿色圆环作为标志。圆环代表工作与休息的循环，缺口代表给连续工作留出休息的空间。整体气质温和、亲切、轻松，带一点活力。

## 造型与颜色

标志采用均匀粗线条、圆润端点和明显缺口，以小尺寸下的视觉存在感与辨识度为首要标准。在 100 单位画布上，圆环半径为 31、线宽为 14，右上缺口为 80 度。主色延续界面绿色 `#2fc186`，整体向右上平移 2 单位以调整视觉重心。

应用图标使用绿色圆角方形底与白色圆环。菜单栏和托盘使用同一轮廓的单色版本，并收紧外部留白。项目介绍使用绿色圆环与简洁的 Sit Break 字样组合。

## 主题适配

macOS 使用单色 PNG 作为 2 倍像素模板，由系统根据菜单栏背景着色。

Windows 使用黑色或白色圆环，跟随系统任务栏的深浅模式。主题检测沿用计时循环，即使计时暂停也会检查；主题变化时才更新图标。读取主题失败时保留当前图标，启动时读取失败则使用彩色应用图标。

Windows 的系统模式与应用模式分别保存在 `SystemUsesLightTheme` 和 `AppsUseLightTheme` 中，托盘选色读取前者。依据：[Microsoft Windows 设置参考](https://learn.microsoft.com/en-us/windows/apps/develop/settings/settings-common)。高对比度及自定义任务栏背景需在对应环境检查。

## 重新生成图标

安装依赖后运行：

```sh
npm run icons
```

此命令在临时目录调用 Tauri CLI，再复制当前桌面应用所需的资源，避免移动端及商店图标进入仓库。后续修改图标时，先编辑对应 SVG，再运行此命令。

## 验证范围
